# SmartForum

A collaborative discussion forum built by a five-person team at Makerere University using Laravel, Vue.js, and Inertia.js.

- *Atugonza Shawn Robin:* Admin features, users table, clickable logo and profile username, pull request merges
- *Petra Ayebare:* Admin panel, notification bell and Reverb setup, quiz system, lecturer module, onboarding, dashboard and lecturer view
- *Rahman Kasule:* Quiz page and buttons
- *Denise Nabachwa:* Group and topic functionality, delete and join/leave buttons
